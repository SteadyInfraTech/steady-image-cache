BUILT FOR THE HARD PARTS

Cache behavior you can reason about.

Image caching is only useful when correctness, resource limits, and failure behavior are explicit.

⌁

Content integrity

Blob digests are verified as content is written. Existing cached files are checked before trusted reads, with corruption recovery and background scrubbing.

Nodes discover ready peers through the Kubernetes API. Peer requests stay cache-only to avoid recursive miss loops.

HOW IT FITS

A local cache with a cluster-wide memory.

Each node runs SIC beside containerd. SIC can import existing content from containerd, serve local cache hits, ask other ready SIC peers, and optionally fall back to explicitly allow-listed registries.

It uses containerd's gRPC content APIs rather than scraping containerd's on-disk layout or invoking a ctr subprocess.
